FCA accuracy presets (updated 2026-10-28)

low:      4 hybridization poles, FCA DLR tolerance 1e-4
modest:   5 hybridization poles, FCA DLR tolerance 1e-4
high:     6 hybridization poles, FCA DLR tolerance 1e-5
veryhigh: 6 hybridization poles, FCA DLR tolerance 1e-6

Named presets own both controls and override fca_aaa_poles and
fca_dlr_tolerance supplied beside them. Actual pole count is capped by the
number available in the accurate AAA expansion. Symmetry is preserved.
OCA, TCA and the dense Dyson mesh retain their independent settings.

custom leaves fca_aaa_poles and fca_dlr_tolerance under explicit control.
For a full-pole reference, use custom, fca_aaa_poles=0 and, for example,
fca_dlr_tolerance=1e-7. Zero poles means all available AAA poles; zero
tolerance means reuse the shared OCA/TCA DLR basis.

The omitted/default mode remains standard for compatibility, with manual
controls supported and default values 0 poles / 0 tolerance. When FCA is
the normalization anchor for higher-order MC, it uses the full accurate
pole table and shared DLR basis regardless of the analytic preset.

The named presets are practical cost/accuracy choices, not universal error
bounds. Check pole and DLR convergence for each input bath. Use the
actual settings, fit errors and ranks printed in ctqmc.log.
