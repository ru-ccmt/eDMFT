DEFERRED UNTIL STRAIN IS VALIDATED: FORCE WINDOW/NORMALIZATION AUDIT
User-requested follow-up, 8 November 2026

Priority: finish and validate the strain implementation first. Afterwards,
measure how much of the new response machinery is necessary for accurate
atomic forces. This is an open task, not an established force correction.

For U_k = Pi_W,k Phi_k X, with X = S^(-1/2) and
S = Sym sum_k w_k Phi_k^dagger Pi_W,k Phi_k, distinguish

  d_A U = Pi_W (d_A Phi) X + (d_A Pi_W) Phi X + Pi_W Phi (d_A X),
  d_A X = (d_A X)_Phi + (d_A X)_(Pi,explicit)
                        + (d_A X)_(Pi,induced).

The force implementation ALREADY includes explicit local-orbital motion and
its normalization derivative. It also contains a complementary-band response
contracted with the existing geometric force kernels at fixed X. Do not
mistakenly describe normalization or all window response as absent.

The later normalization-through-window pass is currently gated by Qstress
(QnormWindow in src/dmft2/l2main.f90). Audit whether an analogous force
contraction is missing or supplied elsewhere; do not declare its physical
size or completeness before checking all cancellations.

Separate two possible extensions:
1. Complete the normalization partner of the SAME explicit geometric window
   response already contracted in forces. This can reuse stored bands and
   derivative kernels without a self-consistent screened-response solve.
2. Add window and normalization response to the induced KS potential. The
   complete derivative requires d_A V_Hxc = f_Hxc d_A n, obtained from the
   screened-response engine (or an independent relaxed finite difference).
   Differentiating the small normalization matrix alone cannot supply it.
   The current response strategy holds local Sigma and double counting fixed;
   this is distinct from including an impurity two-particle vertex.

For either source B, with the appropriate symmetry operation included,
  (d_A S)_(Pi,B) = Sym sum_k w_k Phi_k^dagger (d_A Pi_W,k)_B Phi_k,
  X^(-1) (d_A X)_B + (d_A X)_B X^(-1) = -X (d_A S)_B X.
The inverse-square-root derivative is cheap once its input is known. Its
screened input is the costly part. Basis/metric, fixed-RMT boundary and local
frame conventions must match across all branches; do not double count them.
Explicit and induced terms can cancel, so adding one need not monotonically
improve the force error.

Validation after strain:
- Compare individual analytic forces with derivatives of the consistent
  frozen-Sigma Klein-tangent functional, relaxing charge and updating projector
  normalization at each displaced endpoint. Match particle-number/mu policy.
- Use nonzero-force distortions (e.g. FeSe Se height, SrVO3 O versus V motion),
  not only symmetry-forced zero forces. Check two displacement magnitudes.
- Converge the available response-band complement while keeping the DMFT
  window fixed and avoiding a degeneracy cut at its boundary. Enlarging the
  DMFT window changes the correlated model and is a separate experiment.
- Compare existing forces, explicit normalization-window completion, and the
  complete screened correction; audit radial response consistently as needed.
- Check translation covariance and the acoustic sum, but do not treat a small
  sum of forces as proof that individual forces are accurate.
