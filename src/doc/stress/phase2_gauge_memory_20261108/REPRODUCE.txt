outwin.f90 outwin_response.f90 lapw_radial_response.f90 lapw_radial_capi.f90
-o liblapw_response.so. Dependent radial Hamiltonian/potential modules were
also compiled against the updated module interfaces. The original C ABI is
preserved; the policy-aware constructor is an additional entry point.

wrappers. Full-mesh input/matrix/vector snapshots reside under
/private/tmp/edmft_full_k_response_20261108/full_bz. The previous checkpoint's
native archive preserves the smaller native inputs and endpoint densities.
This checkpoint adds +/-0.125 Ry gauge input copies. Large native H/O/vector
files are deliberately not duplicated into the source repository.

The independent radial reference compiles the user's native WIEN2k OUTWINB
and CHARGE with the small wrappers in reproduce/native. Their source hashes
are recorded. WIEN2k source is not redistributed in this evidence bundle.
The source paths in reproduction scripts can be adjusted for another host.

checkpoint (Hartree radial, periodic charge, mixer normalization). Set
EDMFT_TEST_SOURCE=/Users/haule/dbin for the installed-helper dependency pass.
