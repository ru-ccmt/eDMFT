FINDING AND CORRECTION

WIEN2k24 LAPW1 RINT13 delegates to CHARGE. The historical flag is called
UseSpline, but the actual default is NOT cubic-spline integration: CHARGEF
uses the flat extended-Simpson endpoint rule on the logarithmic radial mesh.
dmft2 ATPARN and the current dftKS RINT13 use the historical alternating
Simpson rule with its origin correction. OUTWIN itself was not the mismatch.
The preceding response loader used ATPARN radial data for both native H/O
and dmft2 projector/density reconstruction. That was inconsistent for native
WIEN2k24 H/O and explains the small constant-gauge residual.

The patch adds an explicit radial quadrature policy. The default native API
and ordinary ATPARN retain their previous behavior. A separate context bank
prepares WIEN2k24 H/O with its own normalization, udot orthogonalization, LO
ABC factors and integrals. Projectors and real-space density retain ATPARN.
Both forward derivatives and their exact transposes follow the corresponding
bank; covectors are summed on the SAME physical potential input.

The loader requires matrix_quadrature="wien2k24" or "atparn" explicitly.
The source backend cannot be inferred from filenames alone. A first-k overlap
closure check rejects an inconsistent quadrature/snapshot. No interpolation
fit or term adjusted to cancel the observed residual is used.

BASIC EQUATIONS

At fixed radial mesh, for a quadrature W and unnormalized OUTWIN solution u,
  I = u^T W u;  v = u / sqrt(I),
  dI = 2 u^T W du,
  dv = du/sqrt(I) - v*dI/(2 I).
For energy derivative functions, normalize the E+/-0.004 Ry solutions with
the SAME W, take their centered difference, and orthogonalize against v
using W. All those discrete steps are differentiated and transposed.
WIEN24 large-component weights for >=8 points are dx*r times
  (17,59,43,49,48,...,48,49,43,59,17)/48.
The small-component weight follows native RELA/NREL conventions. Unlike
ATPARN, this CHARGE branch adds no origin term. Geometry/weights are fixed
in these potential-response tests; geometric strain sources are separate.

For a true constant gauge shift dV=dE_l=dE_LO=dmu=1 Ry,
  d(radial functions)=0, dO=0, d(raw projector)=0, dH=O.
In the O-orthonormal central representation this becomes dH_RR=I and
dH_QR=0. Fixed-N density must not change. The test shifts ALL reference
energies, unlike the ordinary fixed-energy potential-response policy.

COMPLETE UNMIXED CHARGE MAP

  J = N [R E B + D + C] K_Hxc.
N is native normalization at total OUTPUT density; C includes core.
One shared E handles the k sum, normalized projector window and chemical
potential. The new patch changes B's H/O radial policy, not the electronic
window or global normalization algorithm. Both fixed-mu and fixed-N branches
below retain the same outer fixed-target native normalization.
h is an input-density direction amplitude, NOT strain. Errors are relative
Euclidean norms against native charge updates, not pressure/stress errors.
