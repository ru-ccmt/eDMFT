2. EXACTLY WHICH SCALAR IS DIFFERENTIATED?

Suppress k temporarily. In the central orthonormal representation define

  h = diag(epsilon) - mu I,
  h_inf = h + U Sigma_inf U^dagger,
  G(z)^-1 = z I - h - U Sigma(z) U^dagger,
  G_inf(z)^-1 = z I - h_inf.

epsilon are central KS energies; mu is the central chemical potential; U has
band rows and correlated-orbital columns. Sigma and its static limit Sigma_inf
are the exact embedded self-energy inputs used by the existing export, with
the same double-counting convention. Temperature Theta is in energy units,
omega_n>0 are the exported frequencies, and alpha_n their exported weights.

The existing regularized lattice scalar is

  L = 2 sum_k w_k [ Omega_0(h_inf,k)
          + 2 Theta sum_n alpha_n Re { log det G_inf,k^-1(i omega_n)
                                      - log det G_k^-1(i omega_n) } ],
  Omega_0(h_inf) = -Theta Tr log[ I + exp(-h_inf/Theta) ].

The outer factor 2 is the nonmagnetic spin degeneracy; w_k are constant k weights.
This is a static subtraction plus the same discrete Matsubara rule used by
CachedFrozenSigmaResponse.lattice_scalar. No new tail approximation is introduced.

Its derivative contains a direct density/Hamiltonian part and a projector part:

  dL = sum_k <rho_k, dh_k> + dL_projector,
  dL_projector = sum_k <g_U,k, dU_k>,
  <A,B> = Re Tr(A^dagger B).

rho_k already includes the spin and k weights. This patch computes only the
second part. It is not a derivative of the full Klein functional with respect
to charge, and it is not evidence that all its stationary terms can be omitted.
The independent scalar oracle keeps h and mu fixed and varies U only.

For clarity, the existing projector gradient is computed using

  g_U,k = 2 w_k { 2 rho_inf,k U_k Sigma_inf
       + 2 Theta sum_n alpha_n [ G_k U_k Sigma_n
                                + G_k^dagger U_k Sigma_n^dagger
                                - (G_inf,k+G_inf,k^dagger) U_k Sigma_inf ] },
  rho_inf,k = [ I + exp(h_inf,k/Theta) ]^-1.

Here rho_inf does not contain spin/k weights. All subsequent pullbacks use
these weights exactly once. Frequency-dependent work is prepared centrally.

3. NORMALIZATION, WINDOW MOTION, AND THE EMPTY COMPLEMENT

The projector is

  U_k = Pi_W,k phi_k X,
  S = Sym sum_k w_k phi_k^dagger Pi_W,k phi_k,
  X = S^(-1/2).

phi denotes RAW overlaps before window selection and normalization, not U.
Pi_W selects fixed band indices, and Sym is the actual exported real-linear
orbital/equivalent-site symmetry operation. It can include conjugation.
Normalization is evaluated after the global k sum. Its adjoint therefore
uses the transpose of that real-linear map, not an assumed Hermitian projector.

  dU = (dPi_W) phi X + Pi_W (dphi) X + Pi_W phi (dX),
  X^-1 dX + dX X^-1 = -X (dS) X.

The already tested retained-state embedding pullback returns (h_bar,p_bar)
such that

  dL_projector = <h_bar,h_eff> + <p_bar,p_eff>.

The retained subspace R includes all stored KS states, not only the DMFT window
W. Q is the remaining finite LAPW space. Thus two different complements exist:
R\W is treated by explicit retained energy denominators; Q is treated by the
prepared shifted solves. The DMFT window itself is unchanged.

Use an orthonormal central [R,Q] basis. Let E=diag(epsilon_R), H_Q be the
central Q Hamiltonian, and phi_Q the raw overlaps in that subspace. Primes
denote joint covariant native H/O/raw derivatives in the central basis.
O' is the derivative of the overlap matrix. Then

  h_eff = H'_RR - (O'_RR E + E O'_RR)/2,
  p_eff = phi'_R - O'_RR phi_R/2 + T^dagger phi_Q,
  H_Q T - T E = -(H'_QR - O'_QR E).

T is the retained eigenvector's complementary coefficient derivative; it is
not temperature. Columnwise,

  T_j = (epsilon_j I - H_Q)^-1 (H'_QR,j - epsilon_j O'_QR,j).

This formula has the retained energy multiplying O'_QR, not an average of two
eigenvalues. In a full symmetric orthonormalization the mixing is T+O'_QR/2;
the extra term cancels the -O'_RQ phi_Q/2 in the raw-overlap transformation.
The result is precisely p_eff above. Keeping one of these terms without the
other would break basis covariance.

Q must satisfy the installed solver's gap/thermal-empty checks. The projector
readout reuses its prepared factorization; it does not diagonalize high states.
This completes the FINITE basis and does not assert an infinite-basis limit.

4. REVERSE FORMULAS IMPLEMENTED IN THIS PATCH

Define Herm(A)=(A+A^dagger)/2. Reversing the preceding equations gives

  g_H,RR = h_bar,
  g_O,RR = -(h_bar E + E h_bar)/2 - Herm(p_bar phi_R^dagger)/2,
  g_phi,R = p_bar,
  T_bar = phi_Q p_bar^dagger,
  Z_j = (epsilon_j I - H_Q)^-1 T_bar,j,
  g_H,QR = Z/2,
  g_O,QR = -Z E/2.

The joint Hermitian pairing is

  dL_projector = <g_H,RR,H'_RR> + <g_O,RR,O'_RR>
                + <g_phi,R,phi'_R>
                + 2 <g_H,QR,H'_QR> + 2 <g_O,QR,O'_QR>.

It includes all k and orbital blocks. The factors 1/2 in the QR covectors are
essential: QR and RQ are one Hermitian matrix pair. Raw overlaps have no such
duplicate. Real isometric packed coordinates implement exactly this pairing.

There is no extra -(y rho+rho y)/2 term here. That term belongs to the adjoint
of the density-coefficient readout; this operation differentiates a scalar.

5. POTENTIAL PULLBACK AND ONE ADJOINT

Let B map native potential-coordinate variations v to the joint H/O/raw inputs.
It includes spherical/radial matching and LO response, nonspherical radial legs,
interstitial matrix elements and the native potential-coordinate selector.
Let K map input density variations to the Hartree+XC potential at fixed geometry.
The installed complete normalized charge Jacobian is J=N[REB+D+C]K, where
N is output normalization, E the electronic response, R density reconstruction,
D direct moving-basis density, and C core response. These maps and transposes
are shared with the screened solver; no approximate reverse map is substituted.

The new common covectors are

  g_joint = (g_H,RR,g_O,RR,g_phi,R,g_H,QR,g_O,QR),
  g_v = B^T g_joint,
  c = K^T g_v.

For strain direction nu, v_nu = v_explicit,nu + K q_nu. Consequently this
potential-dependent projector contribution is

  dL_projector,potential,nu = g_v^T v_explicit,nu + c^T q_nu,
  (I-J)^T lambda = c,
  dL_projector,potential,nu = g_v^T v_explicit,nu + lambda^T s_nu.

The adjoint is independent of nu: compute it once and contract many sources.
This is only ONE contribution to a complete a_nu+c_total^T q_nu decomposition.
In particular it excludes the direct geometry of H/O/phi at fixed potential,
direct density/Hamiltonian terms, and the reconciliation with existing stress.

adjoint_contractions REQUIRES an explicit potential matrix, one column per
source. No default zero is provided, because Kq is not the total potential.
Returned numbers are energy derivatives in Ry per supplied perturbation
parameter, without volume division. Reports keep stress_applied=false.
