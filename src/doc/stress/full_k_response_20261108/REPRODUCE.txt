This package records the 8 November 2026 full-k phase-2 checkpoint.

The native endpoint matrices/vectors are intentionally not archived here.
They remain at /private/tmp/edmft_full_k_response_20261108 and full_bz/.
The report JSON contains SHA256 fingerprints of the exact loader inputs.
The native archive preserves small input files, endpoint charge densities,
core endpoints, perturbation directions and the portable potential/core state.
It is not a complete self-contained binary execution environment.

Reproduction scripts record the original host paths and isolated native run
commands. Adjust their scratch roots when moving to another host. The native
lapw1 exporter and dmft2_response, plus liblapw_response, must already be built.
The Python helper patch is full_k_response.patch; it does not change Fortran.
No user material calculations were overwritten during these checks.

The fixed-N endpoint helper uses an independent nonlinear N(mu) root. The
scalar-resolvent trace was checked against dense matrix inverses before use.
No analytic dmu was used to construct the native fixed-N finite differences.

thread. run_all_tests.py selects the repository suite plus the two new tests.
