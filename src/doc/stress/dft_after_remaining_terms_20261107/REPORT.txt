Method and validation
Fresh central lapw0 -> dftKS (x_dmft.py lapw1) -> current WIEN2k-24 lapw2 -> lcore;
merge_scf.py and mixer independently verify total stress. Ordinary charge was not
reconverged: these stress-only corrections leave potentials and core density byte-identical
on each input. The source endpoint energies are therefore unchanged by the fixes.
All runs are isolated copies; the original material directories are preserved.
Before/after use the same fresh valence stress and compare old/new lapw0 and lcore
on exactly the same central input charge. Both include the earlier G1/G2 repairs.
Endpoint constant Eorb_imp.dat offsets, where present, are identical and cancel.
FeSe current endpoint energies give 12.138890 GPa rather than the earlier archived
12.138195 GPa; these differ by only 0.000695 GPa and refer to distinct saved runs.

contains 75 points. It was regenerated completely in the isolated test. Both endpoint
vectors contain 75 points and match the regenerated central plane-wave sets and bands.
The partial vector in the user directory was not overwritten.

WIEN2k lapw1 cross-check (secondary control)
Repeating the same central calculation with WIEN2k lapw1 instead of dftKS gives:
  SrVO3: 8.627203646 GPa; charge residual 1.3e-06
  FeSe: 12.234759566 GPa; charge residual 1.04e-05
  MnTe: 16.939413966 GPa; charge residual 5.25e-05
These controls have larger charge residuals, especially MnTe. The primary table
uses dftKS because that is the band solver used to converge the reference triplets.
No source or executable was changed in this follow-up. The residual DFT discrepancy
is not resolved; FeSe and MnTe improve modestly, SrVO3 is essentially unchanged.
