1. SHARED SOURCE AND SCREENING OPERATION

A denotes either homogeneous strain or a static zone-center displacement.
The caller supplies physical source derivatives in one consistent central
representation. The fixed-local-Sigma charge Jacobian remains

  J = N [R E B + D + C] K.

K: charge -> Hartree/XC potential;
B: potential -> joint Hamiltonian, overlap and raw-projector perturbation;
E: joint perturbation -> density-matrix coefficient response;
R: coefficient response -> spatial valence density;
D: direct basis-density response to potential;
C: core response to potential;
N: derivative of output normalization with respect to raw total output density.

The explicit source must also include the GEOMETRY derivative of output
normalization. This was available in NativeChargeNormalization.explicit_source
but was not yet accepted by ChargeResponseChain.explicit_source. It is now
connected as a separate term:

  b_A = N [R E s_band + s_basis + s_core
           + (R E B + D + C) s_potential] + s_normalization.

s_normalization is ALREADY in normalized-output coordinates. Passing it
through N again would be incorrect. The new tests explicitly distinguish
these two operations using an independent nonlinear endpoint with changing
charge-integration weights and nontrivial normalization.

For fixed RMT, with M=m.q0, I=i.q0, alpha=(Q-M)/I and p0 the interstitial part
of the raw central output, the existing normalization helper supplies

  s_normalization = p0 [Q_A - (partial_A m).q0
                            - alpha*(partial_A i).q0]/I.

Here q0 must include valence AND core before normalization. This increment
connects that supplied source; it does not derive m_A/i_A for general atomic
motion or six strains, or infer a nuclear displacement from an atom index.

The new solve_perturbation operation returns (dn, dV, joint_band, report):

  (I-J) dn = b_A,
  dV = s_potential + K dn,
  joint_band = s_band + B dV.

The reconstruction prevents omitting or double-counting the explicit potential
source when extracting a screened electron-phonon perturbation. The same J can
serve several sources at the same central state. The existing scalar adjoint
can still serve many sources for ONE observable; it does not supply all e-ph
matrix elements from one adjoint solve.

The new solver requires normalization_source explicitly. A zero vector is valid
only if that geometry/target contribution vanishes or is already accounted for
consistently. The older explicit_source method keeps None as a backward-
compatible fixed-normalization-geometry convention. Krylov failure still raises
ResponseConvergenceError; a failed solve is not published as a physical result.

2. INVERSE GREEN FUNCTION IN MOVING LAPW COORDINATES

At the reference KS gauge, O0=I and H0=diag(epsilon). The code's compact U has
band rows and local-orbital columns; P=U^dagger in the preceding chat notation.
S(i*omega_n) is the stored local Sigma minus double counting, held fixed.

  A_k(i*omega_n) = G_k^-1
                = z_n O_k - H_k - U_k S_n U_k^dagger,
  z_n = i*omega_n + mu.

For a supplied direction (H1,O1,phi1), the symmetric orthonormalization used by
the existing electronic response gives

  h1   = H1 - (O1 H0 + H0 O1)/2,
  raw1 = phi1 - O1 phi0/2.

Use the EXISTING embedding_response(h1,raw1) to differentiate the finite band
window, k-summed overlap symmetry and inverse-square-root normalization. This
produces U1_orth. No pseudoinverse or duplicate normalization is introduced.

To recover the covariant embedding in the original moving basis,

  U_cov = O^(1/2) U_orth,
  U1_cov = U1_orth + O1 U0/2.

The new prepared readout evaluates

  A1 = z_n O1 - H1 - U1_cov S_n U0^dagger
                    - U0 S_n U1_cov^dagger + mu1 I.

The added metric leg belongs to this new inverse-propagator readout. It is
NOT a newly discovered missing term in the existing density-response path:
that path already transforms density coefficients back with its metric terms.

A1 is generally non-Hermitian at positive Matsubara frequency. It must not be
Hermitized or multiplied by k, spin or Matsubara quadrature weights. The exact
matrix identity for the corresponding coefficient Green function is

  G1 = -G0 A1 G0.

The common orthonormalization input transformation is now shared by the old
generalized density response and the new readout. The old equations and
numerical behavior are preserved; their full regression suite passes.

For fixed chemical potential, use mu1=0. For fixed N, take mu1 from the global
generalized_response of the TOTAL screened direction. Never enforce fixed N
separately at each k or frequency. Neither a local self-energy derivative nor
a double-counting derivative is inferred from mu1.

A1 is still a coefficient-space derivative, not automatically a physical e-ph
g matrix. For a pure basis change B(t)=B0(I+t L),

  A1 = L^dagger A0 + A0 L,

although no physical operator changes. This identity is tested, and pulling
back to the original basis cancels it. Native basis connections, physical
vertex conventions and phonon mass/eigenvector factors remain necessary for
a final e-ph exporter.

3. API EXAMPLE

For an already prepared complete q=0 charge chain and a caller-supplied physical
source in its exact coordinates:

  dn, dV, band, report = chain.solve_perturbation(
      s_band, s_basis_density, s_core, s_potential,
      normalization_source=s_normalization,
      rtol=1e-10, atol=1e-12)

With the stored-band GeneralizedCoordinates/CachedFrozenSigmaResponse adapter:

  dH, dO, dphi = coordinates.unpack(band)
  drho, number = model.generalized_response(dH, dO, dphi, fixed_number=True)
  readout = model.prepare_inverse_response(dH, dO, dphi, dmu=number['dmu'])
  dGinv = readout.block(kpoint=0, frequency_indices=slice(0, 32))

prepare_inverse_response computes the projector derivative once over all k
points in that context. block() only performs low-rank embedding products and
matrix additions for the requested frequencies. No new diagonalization,
resolvent inversion, Matsubara sum or density-cache construction occurs there.
Output allocation is bounded by the explicitly requested frequency block.
Caller-owned input arrays cannot change the prepared derivative.

This readout currently belongs to the stored-band CachedFrozenSigmaResponse
interface. It does not automatically reconstruct discarded LAPW coefficients
from EmptyComplementResponse or decode ComplementMatrixCoordinates. That
extension must use the appropriate retained/complement basis maps; it is not
silently approximated here.

4. TESTS

Eight new tests supplement the preceding 161; the selected suite now has
169 passing tests and zero skips. New independent checks cover:

  * G^-1 endpoints with explicit H/O/raw-projector changes. Each endpoint
    rediagonalizes the generalized Hamiltonian, selects its window, recomputes
    normalization and reconstructs the covariant embedding. Checks use two
    inequivalent k points, unequal weights, complex orbitals, a nontrivial
    overlap-symmetry map, and a frequency-dependent matrix self-energy.
    Halving h from 1e-4 to 5e-5 reduces derivative error by >3.7; final absolute
    Frobenius errors are below 1e-5 for the selected frequencies.
  * Independently inverted endpoint Green functions versus -G A1 G.
  * Pure-basis covariance and zero physical perturbation after pullback.
  * Uniform H shift cancelled by the globally determined fixed-N mu1.
  * Chunked versus complete frequency readout; no eigensolve, inversion,
    repeated projector preparation or caller-array mutation.
  * Index, stale-central-state and chemical-potential validation.
  * Explicit normalization geometry against nonlinear normalized endpoints.
  * Screened source versus a dense solve, and reconstruction of the original
    complete one-step response equation using total potential/band inputs.

These are synthetic but nontrivial matrix/spatial controls, not a material
phonon calculation. Earlier native FeSe/SrVO3 and quadrature tests remain in
the selected suite/evidence. No new native displacement endpoint, pressure,
phonon frequency or electron-phonon coupling is claimed by this checkpoint.

5. REMAINING WORK

Main strain path remains in phase 2: reusable full-k valence preparation and
broader number/gauge validation before the physical screened solve. This
shared interface work does not finish phase 3.

The first phonon milestone is one native zone-center optical displacement:
construct nuclear, moving-sphere, basis, core and normalized-projector sources;
represent symmetry-breaking response channels even when the central state has
higher symmetry; compare analytic response with controlled displaced endpoints.
Rigid translations provide a covariance/acoustic-sum control. A uniform strain
is not a rigid zone-center acoustic translation.

A displacement may break site equivalence even at q=0. Ground-state-only star
and harmonic reductions must not project away the induced response. The new
source interface does not automatically expand those representations.

Finite q requires k-to-k+q blocks, generally non-Hermitian/rectangular response
coordinates, G+q fields, the correct phonon symmetry/phases and a separate
screening operator per q. Finite bosonic frequency and the impurity vertex are
further extensions. No finite-q implementation is enabled by this patch.
