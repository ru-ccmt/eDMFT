DERIVATION AND BOOKKEEPING

At fixed local self-energy S(w)=Sigma_imp(w)-V_DC, use the same exported
temperature, Matsubara nodes/weights, k weights, and orbital symmetrization
as dmft2. The central band basis is orthonormal. U has bands as rows and local
orbitals as columns. W is the fixed-index DMFT window, Q the stored complement.

  P_k = Pi_W,k phi_k,
  A = Sym sum_k w_k P_k^dagger P_k,
  X = A^(-1/2),
  U_k = P_k X.

For a Hermitian band-potential perturbation dH in a fixed LAPW basis,

  a_QW = dH_QW/(epsilon_W-epsilon_Q),
  dP_Q = a_QW phi_W,  dP_W = a_QW^dagger phi_Q,
  dA = Sym sum_k w_k (P_k^dagger dP_k + dP_k^dagger P_k),
  dU = dP X + P dX.

The inverse-square-root Frechet derivative is evaluated on the saved active
orbital support. In the eigenbasis of X, let r_i=1/x_i (eigenvalues of sqrt(A)):

  (dX)_ij = -(dA)_ij/[r_i r_j (r_i+r_j)].

This map is self-adjoint on Hermitian matrices. The actual Sym map need NOT
be treated as complex-linear or assumed self-adjoint; its real/imaginary
matrix-unit action is exported by dmft2 and transposed explicitly.

The fixed-mu electronic derivative is

  dG_k(w) = G_k(w) [dH_k + dU_k S(w) U_k^dagger
                            + U_k S(w) dU_k^dagger] G_k(w).

Subtract the static resolvent response before summing. Restore its density
with the Frechet derivative of the Fermi matrix function. Exported quadrature
weights occur ONCE, after the two resolvents have been multiplied. The returned
band density contains spin factor 2 and w_k. Its caller must not reweight it.

For fixed N, b=d(rho)/dmu, a^T rho=sum_k Tr(rho_k), kappa=a^T b:

  drho_N = [I - b a^T/kappa] drho_mu.

Reverse this as [I-a b^T/kappa], not as the same forward projection. Small
compressibility is rejected; fixed-mu calculations remain a separate branch.

ALL TRANSPOSES use the real Frobenius pairing Re sum(conj(y)*x). In particular,

  (D -> G D G)^* Y = G^dagger Y G^dagger.

The reverse projector chain undoes compacting, U=P X, the Frechet derivative,
orbital symmetry, the weighted k sum, and window mixing, in that order. The
last Hermitian projection supplies the factor 1/2 required by the two QW/WQ
blocks. Complex, non-self-adjoint symmetry controls test this explicitly.

COMMON PROJECTOR GRADIENT AND ONE ADJOINT

An independent scalar oracle is implemented:

  L(H,U) = 2 sum_k w_k { Omega(H_inf,k)
       + 2T sum_n w_n Re[log det(iw_n-H_inf,k)
                       -log det(iw_n-H_k-Sigma_emb,k(w_n))] },
  Omega(H_inf) = -T Tr log(1+exp(-H_inf/T)).

All Hamiltonians in this expression are relative to the same fixed mu.
This is the regularized LATTICE SCALAR, NOT the full Klein functional.
Its direct derivative with respect to H at fixed U is the weighted density.
Its additional H -> U(H) derivative is a common Hermitian covector R:

  dL = Re sum_k Tr[(rho_k+R_k) dH_k].

projector_potential_gradient() returns R alone. Both its isolated derivative
and the full rho+R derivative agree with independent scalar finite differences.
It is the same covector for every strain direction. This supplies an explicit
proof of the common-gradient property for the WINDOW/NORMALIZATION chain.
It does not establish the radial and moving-basis parts of that property.

For band-potential map B, spatial potential response K, and charge response q_nu,

  v_nu = v_exp,nu + K q_nu,
  c = K^T B^T R,
  Delta D_nu = a_nu + c^T q_nu,
  (I-J) q_nu = b_nu,
  (I-J)^T lambda = c,
  Delta D_nu = a_nu + lambda^T b_nu.

This is the correction after removing already implemented stationary terms;
R must not be confused with rho or added again as a direct Tr(rho dH) term.
Different observable gradients require different solves. The total of several
validated scalar corrections can use the sum of their gradients in one solve.

For eta=(exx,eyy,ezz,2eyz,2exz,2exy), energy derivatives divided by Omega give
the corresponding tensile stress components, including shear without another
factor of two. Hydrostatic dGamma/deta=sum_nu=xx,yy,zz D_nu; mean tensile
stress divides this by 3*Omega, pressure is minus that mean.

WHY THE SPEEDUP IS LARGE

The first implementation cached only central eigensystems and Green functions.
That improved the electronic action by only 1.1-1.3x. The larger improvement
comes from precontracting the Matsubara dependence once per central context:

  * WW response to Hermitian dH_WW: a real Nw^2 by Nw^2 map.
  * WW response to complex dU_W: a real Nw^2 by 2*Nw*Norb map.
  * WQ response: independent small maps for each excluded stored band.
  * QQ dynamic/static contribution: cancels identically, so is not stored.

The global normalization coupling remains an explicit small orbital operation;
we do not build a dense charge susceptibility. Reverse actions transpose these
same precontracted maps. Static Fermi divided differences remain exact within
the exported band space. If the memory cap does not fit all k points, the rest
use the original frequency-block operation; partial-cache results are tested.

USAGE FOR DEVELOPERS

Read a central EDMFT_RESPONSE_EXPORT:
  from frozen_sigma_tangent import CachedFrozenSigmaResponse
  model, records = CachedFrozenSigmaResponse.from_export(prefix, cache_mb=1024)
  model.prepare()
  drho, info = model.response(dH, fixed_number=True)
  dH_covector = model.adjoint(density_covector, fixed_number=True)
  R = model.projector_potential_gradient()

For a batch of band-potential directions saved as [direction,k,band,band]:
  python ~/dbin/frozen_sigma_tangent.py --export PREFIX --input directions.npy \
      --output responses.npy --cache-mb 1024
Add --adjoint for the reverse action, or --fixed-mu for that ensemble.
Use --projector-gradient instead of --input to export the common covector.
The output density matrices are signed, k/spin weighted, in the central gauge.

The old signed-density-file interface also accepts --backend cached:
  python ~/dbin/frozen_sigma_response.py --export PREFIX --potential dH.npy \
      --output response_rho --backend cached --cache-mb 1024

NATIVE RADIAL EXTENSION COMPLETED IN THE SAME DEVELOPMENT PASS

src/dmft2/atpar/outwin_response.f90 is included in libatpar's object list.
It does not replace OUTWIN or change ordinary ATPARN execution. The native
response worker can reuse its prepared contexts later; production stress does
not call it yet. Its independent test driver is
  python src/dmft2/tests/check_radial_response.py --work NEW_DIRECTORY
Optional --case-directory PATH entries test actual VSP potentials read-only.

Let y_k=(A_k,B_raw,k) and f_k=L_k y_k. An implicit Adams step is

  (s I-L_k)y_k = s y_(k-1) + sum_j w_j f_j.

The startup uses the actual fourth-order coefficients; subsequent steps use
the fifth-order coefficients already installed in OUTWIN. At fixed radial
mesh, nuclear charge and l,

  dy_k = (s I-L_k)^(-1) [s dy_(k-1) + sum_j w_j df_j + dL_k y_k],
  df_k = L_k dy_k + dL_k y_k.

L=[[-x,u],[-y,x]], x=-dx, u=c*dx*r+phi,
y=-l(l+1)*x^2/u+phi, phi=(2E-2V/r)*dx*r/c. Thus

  dphi = (2 dx/c)(r dE-dV),
  dL = [[0,dphi],[-(1+l(l+1)x^2/u^2)dphi,0]].

V here is r times the spherical potential in Hartree; E is Hartree. The
reverse action uses (s I-L_k)^(-T) and accumulates covectors backward through
the derivative history. Complexity and storage are O(Nrad), not O(Nrad^2).
The stored small-component scaling and AP/BP radial derivatives are included.

Normalization is differentiated using the exact discrete RINT13 weights,
including the origin term, even/odd grid convention and NREL 1e-22 small
component metric. The radial pair differentiates the actual +/-0.002 Hartree
energy stencil (factor 0.25/0.002, yielding the Ry energy derivative), followed
by ATPARN's orthogonalization. It does not invoke a continuous differential
identity that the implemented finite stencil only approximately satisfies.

The local-orbital coefficient helper returns the tiny 3-by-10 Jacobian of
ABC with inputs (p,dp,pe,dpe,pei,plo,dplo,pi12lo,pe12lo,RMT). It handles LAPW
LO, first APW+lo, and higher APW+LO. The CLO=200 cap is differentiated on each
smooth branch; evaluation at the nondifferentiable join is rejected. We follow
the actual RMT^2 factors in ABC; replacing them with an exact boundary-matrix
inverse would change the basis algorithm and requires a separate audit.
