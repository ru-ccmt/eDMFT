This implements the next native component after outwin_response: assemble
the radial tangent/adjoint into the actual LAPW/APW+lo basis, its MT overlap,
and fixed radial projector-5 overlaps. It also extends the cached electronic
response to accept a changing overlap metric and explicit raw-projector
derivatives, with exact discrete transposes for the adjoint solve.

This is NOT the complete native screened stress implementation. Native
Hamiltonian and spatial-density assembly, Hartree/XC and core response, energy
searches and six physical strain sources still need connected forward/reverse
maps. No new finite-difference versus analytic pressure comparison is claimed.

1. THE RADIAL REPRESENTATION

One context belongs to one inequivalent atom and angular momentum l. It caches
normalized u, the implemented energy derivative udot, and ordinary LO radial
functions u_j. Their arrays have columns (A,B,AP,BP), where A=r*u_large,
AP=r*d(u_large)/dr, and B/BP follow OUTWIN's stored small-component convention.
R is the fixed muffin-tin radius. Potentials passed to the new interface are
r*V_spherical in Ry; all supplied energy parameters and their variations are
also Ry. Conversion to the existing Hartree radial solver is internal.

udot is ATPARN's normalized +/-0.002 Hartree energy stencil followed by its
orthogonalization against u. It is differentiated as an algorithm, not by
replacing it with the continuum identity (H-E)udot=u.

For fixed plane-wave boundary data j=j_l(qR), j'=q*j_l'(qR), define
  p=u_large(R), d=u_large'(R),
  pe=udot_large(R), de=udot_large'(R).
Here de denotes a boundary slope, not an energy variation.

Factoring out the fixed common angular/phase factor 4*pi/sqrt(Omega), the
production LAPW radial combination is
  f = alpha*u + beta*udot,
  alpha = R^2 (j'*pe-j*de),
  beta  = R^2 (j*d-j'*p).
For APW it is alpha=j/p, beta=0. In this module geometry, j, j', R and the
common angular/phase factor are held fixed. The radial response is
  df = dalpha*u + alpha*du + dbeta*udot + beta*d(udot).

Each complete local orbital is
  f_j = a_j*u + b_j*udot + c_j*u_j,
  df_j = da_j*u + a_j*du + db_j*udot + b_j*d(udot)
                         + dc_j*u_j + c_j*du_j.
All ABC coefficient branches are differentiated: ordinary LAPW LO, first
APW+lo, and higher APW LO. ABC inputs include the radial norms and cross
overlaps; those derivatives are included before applying its small Jacobian.
The first APW+lo contains only u and udot; its nominal LO energy has no effect.
DIRACOUT p1/2 orbitals are explicitly rejected, not silently treated as OUTWIN.

The module returns the radial components before complex angular factors and
band coefficients. It does not yet assemble all atom/l/m blocks into band H.

2. OVERLAP AND RAW PROJECTOR FACTORS

Let W be the exact discrete RINT13 quadrature metric, including its origin
term and small-component weight. For real radial basis factors f_i,
  O_ij = sum_(r,c) W_rc f_i,rc f_j,rc,
  dO_ij = sum W (df_i*f_j + f_i*df_j).
Both bra and ket terms are required for off-diagonal matrices.

For fixed on-disk radial projector chi and Rint13n weights Wp,
  phi_i = sum_(r,c=large,small) Wp_rc f_i,rc chi_rc,
  dphi_i = sum Wp_rc df_i,rc chi_rc.
No projector boundary value is set to zero. In NREL, Rint13n drops the small
component exactly, whereas RINT13 uses a factor 1e-22; the code preserves
both conventions. With fixed R and fixed radial chi there is no moving-boundary
term in this radial-potential derivative. Strain geometry and transport are
separate sources and cannot be inferred from this equation alone.

For an arbitrary real overlap covector Y (not necessarily symmetric) and raw
projector covector z, the radial pullback is
  fbar_i = sum_j (Y_ij+Y_ji) W f_j + z_i Wp chi.
The complete reverse routine then undoes LO coefficients, matching amplitudes,
radial normalization and OUTWIN's discrete recurrences. It returns covectors
for r*dV in Ry, the central energy in Ry, and each LO energy in Ry. All input
and output pairings are ordinary real sums; callers must not add quadrature
or convert energy units a second time.

3. EXPLICIT PROJECTOR CHANGES IN THE CACHED BAND RESPONSE

H0=diag(epsilon_k) and O0=I in the central KS gauge. W now denotes the fixed
index DMFT band window (not the radial quadrature); Q is its stored complement.
Let phi_k contain unnormalized overlaps <basis|local orbital>, including Q.
  P_k = Pi_W,k phi_k,
  S = Sym sum_k w_k P_k^dagger P_k,
  X = S^(-1/2), U_k = P_k X.

The new interface accepts an explicit dphi in addition to dH. It computes
  dP = dPi_W phi + Pi_W dphi,
  dS = Sym sum_k w_k (P^dagger dP + dP^dagger P),
  dU = dP X + P dX.
For QW, dPi_QW=dH_QW/(epsilon_W-epsilon_Q), and WQ is its adjoint. Only W rows
of explicit dphi enter Pi_W*dphi; adding its Q rows would be incorrect.
The inverse-square-root Frechet derivative and the actual exported real-linear
orbital symmetry map are shared by both terms. No normalization is omitted.

embedding_pullback returns covectors for BOTH dH and dphi. Existing
embedding_adjoint still returns only the dH covector for compatibility.
response(..., raw_derivative=dphi) and adjoint(..., return_raw=True) provide
the same extended electronic map and transpose. The fixed-N correction is
applied once to the combined response. Existing potential-only calls retain
their numerical result, as checked by the previous regression suite.

4. CONSISTENT CHANGING-METRIC INTERFACE

Inputs dH, dO and dphi must all be in the SAME central coefficient gauge.
Do not pass an already orthonormalized perturbation as dH here. Let T=O^(-1/2).
At O0=I, dT=-dO/2, so the orthonormal perturbations are
  h = dH - (dO H0 + H0 dO)/2,
  phi1 = dphi - dO phi/2.
Apply the normalized-window electronic response to (h,phi1), obtaining r1.
Convert back to contravariant density coefficients:
  rho1 = r1 - (dO rho0 + rho0 dO)/2.
The weighted density matrices already include spin factor 2 and k-point
weights. rho0 is computed during cache preparation from the same regularized
resolvent sum as the independent endpoint oracle. It requires no extra solves.

The physical number derivative is
  dN = sum_k Tr[rho1_k + rho0_k dO_k].
Tr(rho1) alone generally does not vanish, even at fixed N. Likewise physical
density reconstruction must include the derivative of the basis functions:
  d[B rho B^dagger] = dB rho0 B^dagger + B rho1 B^dagger + B rho0 dB^dagger.
Dropping either conversion would break a pure basis-change test.

All complex adjoints use Re sum(conj(y)*x). If the orthonormal electronic
pullback gives hbar and phibar, the generalized pullback is
  Hbar = hbar,
  phibar_general = phibar,
  Obar = -(H0 hbar+hbar H0)/2
         -Herm(sum_(orbital,cix) phibar phi^dagger)/2
         -(rho0 y+y rho0)/2.
The last term uses the original density covector y, before any fixed-N
projection. The implementation and tests enforce this distinction.

API:
  drho,info = model.generalized_response(dH,dO,dphi,fixed_number=True)
  Hbar,Obar,phibar = model.generalized_adjoint(y,fixed_number=True)
  rho0 = model.central_density()
  R_H,R_phi = model.projector_gradients()
The final pair is the extra normalized-projector gradient of the regularized
lattice scalar, not the full Klein functional and not an additional direct
Tr(rho dH) term. These components prepare its later composition with native
maps; they do not add a new stress term to production by themselves.

5. VALIDATION

Native tests: 8 synthetic controls plus 16 actual SrVO3 NREL atom/l channels
and 8 FeSe RELA atom/l channels. Cases include no LOs, two ordinary LOs,
first APW+lo and higher APW LO. Fixed radial projectors are finite at RMT.
Where an atom/l matches projectorw.dat, that actual radial projector is used;
other channels use an explicitly identified smooth synthetic projector.

Maximum relative errors over 32 controls:
  Central assembled values versus independent ATPARN/ABC:    1.55e-11
  Basis directional derivative versus independent endpoints: 1.26e-7
  Overlap/projector derivatives versus independent endpoints:4.94e-7
  Complete basis transpose:                                 7.26e-13
  Overlap/projector -> potential/energies transpose:          1.13e-13

Material-only overlap/projector finite-difference errors:
  SrVO3: 3.16e-7; FeSe: 1.55e-8.
Tests sample three finite-difference steps and report the best resolved error;
the nested finite-energy stencil eventually introduces cancellation noise.
These are directional operator tests, not converged stress calculations.

The full synthetic nonlinear electronic endpoint separately rediagonalizes H,
forms Pi_W, renormalizes projectors, computes the full resolvent density, and
transforms back with O^(-1/2). Its generalized derivative shows second-order
finite-difference convergence. Complex nonsymmetric orbital symmetry maps,
both particle-number ensembles, and full/partial/zero caches are covered.

Pure basis change: for B(t)=B0(I+tA), arbitrary complex A,
  dO=A^dagger+A, dH=A^dagger H0+H0 A, dphi=A^dagger phi.
The physical density must remain unchanged, implying
  rho1=-A rho0-rho0 A^dagger.
Both the unit test and actual full material exports satisfy this identity.

6. MATCHING OBSERVATION AND ITS LIMIT

For the implemented LAPW formula, the boundary value contains
  W_R = R^2 (d*pe-p*de).
It equals unity only to the accuracy of the implemented radial convention and
finite energy stencil. Replacing the derivative by an exact boundary-matrix
inverse changes that algorithm. The new assembly differentiates the actual
formula instead. In the FeSe l=3 controls W_R was 1.00000163 (Fe) and
1.00001231 (Se). Its directional derivatives were about 3.32e-8 and -2.67e-7
for the stated test direction. This establishes a small difference between
the two algorithms; it does NOT establish a correction of a particular GPa
magnitude. No production matching formula was changed.

7. NEXT NATIVE CONNECTIONS

Assemble the complete band dH, dO, raw dphi and spatial density maps in one
consistent coefficient gauge. The new radial module supplies the radial
factors of dO/dphi and of those remaining assemblies. Direct kinetic and
nonspherical-potential terms in dH must retain the code's own integration and
boundary conventions; continuous radial identities cannot simply be imposed
in RELA. Automatic energy searches, core and DIRACOUT need their own paired
derivatives. Then connect Hartree/XC and normalization to the screened solver,
verify native forward/reverse identities, and compare physical strain sources
and total stress with the existing finite-difference workflow. Until that is
done, the current production response remains the reference path.
